Správce webu a kontakt

Dotazy k ochraně osobních údajů a uplatnění práv: vyvoj@dameappku.cz

Web lzs-line.cz je neoficiální informační web o stanici Kryštof 07. Neobsahuje přihlášení, formuláře ani komentáře a sám žádné osobní údaje neukládá. Nepoužívá cookies.

Co se děje při návštěvě

Hosting webu zajišťuje GitHub Pages (GitHub, Inc.) a síťové služby Cloudflare. Při každé návštěvě tito poskytovatelé technicky zpracují IP adresu návštěvníka, aby mohli stránku doručit a zajistit bezpečnost. Písma a mapová knihovna jsou uložené přímo na tomto webu, nenačítají se od třetích stran.

Služby třetích stran, které stránka volá

Aby web zobrazoval živá data, prohlížeč návštěvníka se po načtení stránky připojí k těmto službám. Jejich provozovatelé při tom získají IP adresu návštěvníka a běžné technické údaje prohlížeče.

Některé z těchto služeb mají sídlo mimo EU (zejména v USA), takže IP adresa může být předána do třetí země. Podrobnosti najdete v zásadách ochrany osobních údajů jednotlivých provozovatelů.

Vaše práva

Máte právo na přístup k údajům, jejich opravu či výmaz, omezení zpracování a vznesení námitky. Stížnost můžete podat u Úřadu pro ochranu osobních údajů (uoou.gov.cz). Údaje, které zpracovávají provozovatelé služeb výše, spravují oni sami.
